# projectpenney
Uses the Monte Carlo method to simulate and visualize two versions of the Humble-Nishiyama (H-N) Randomness game, which is a variation of Penney's Game using a standard 52-deck of cards.


# Repository Guidance
- datagen.py: Handles data generation and storage
- dataproc.py: Does processing, scoring, and summarizing
- datavis.py: Creates heatmaps from simulated data
